# LightShot前端UI库

LightShot前端UI库，支持原生HTML，立即下载，按需引入项目使用

该前端UI库采用CZ工作室新阅浅蓝色主题，加入了各种动画，充实网页效果，实现美观

# 引入UI库

1.下载该项目源代码

2.打开一个要使用UI库的<u>原版HTML</u>项目

3.将源代码（js文件）拖进项目目录

4.要使用组件，请在HTML文件中添加以下标签：

`<script src="源代码路径"></script>`

其中“源代码路径”指的是存放LightShot代码文件的路径

5.使用标签：

`<ls-text>文字</ls-text>`（示例）
